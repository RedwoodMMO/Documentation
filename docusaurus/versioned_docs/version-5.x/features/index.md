This section is the most up-to-date reference of the features available in Redwood. If you haven't integrated Redwood into your project yet, start with [Getting Started](../getting-started/overview.md); these pages assume the basic setup from there is done.

| --- | --- |

| Realms | [Realms](./realms.md), including adding realms, the Default Proxy, and maintenance |
| Getting players into servers | [Ticketing](./ticketing/overview.md) (matchmaking, queuing, and custom flows) |
| Game servers | [Hosting providers](./game-servers/hosting/overview.md), [zones](./game-servers/zones.md), [sharding](./game-servers/sharding.md), and [instanced dungeons](./instanced-dungeons.md) |

| Storage | [Database](./data/storage/database.md), [Redis](./data/storage/redis.md), and [blob storage](./data/storage/blob-storage.md) |
| Social | [Friends](./social/friends.md), [realm contacts](./social/realm-contacts.md), [guilds & alliances](./social/guilds-alliances.md), [parties](./social/parties.md), and [text chat](./social/text-chat.md) |
